# 🚑 Fichas Med+ | Triagem Visual OCR

Aplicação desktop em Python (CustomTkinter) construída sob a arquitetura **MVC** para automação de triagem visual e extração OCR de fichas de APH (Atendimento Pré-Hospitalar) utilizando a **API oficial do Google Gemini (`google-genai`)**.

---

## 🚀 Como Executar o Projeto

### 1. Clonar o repositório
```bash
git clone [https://github.com/TEU-USUARIO/fichas-med-plus-ocr.git](https://github.com/TEU-USUARIO/fichas-med-plus-ocr.git)
cd fichas-med-plus-ocr
